# Nike Adapt Open  (v1.0)

IT: app Android open source e gratuita per usare le Nike Adapt BB 2.0 dopo la fine del supporto dell'app ufficiale. Ideata da The Citadel.
EN: free, open-source Android app to keep using Nike Adapt BB 2.0 shoes after the official app was discontinued. Created by The Citadel.

Discord: https://discord.gg/CBAVmcbUM5

## Come compilarla / How to build
1. Installa Android Studio / Install Android Studio.
2. File > Open e scegli questa cartella / File > Open and select this folder.
3. Per un APK firmato / For a signed APK: Build > Generate Signed App Bundle / APK > APK > release.

## Funzioni / Features
- Lingua inglese o italiana (scelta al primo avvio, cambiabile dalla home) / English or Italian (chosen on first launch, switchable from home).
- Termini d'uso da accettare al primo avvio / Terms of use to accept on first launch.
- Due schermate separate, scarpa sinistra e destra / Two separate screens, left and right shoe.
- Lacci: ALLARGA e STRINGI, tieni premuto per andare al massimo / Laces: LOOSEN and TIGHTEN, hold to go to the maximum.
- 3 preset per scarpa / 3 presets per shoe.
- Batteria di ogni scarpa / Battery of each shoe.
- Luci, identifica, sensore del piede, console avanzata / Lights, identify, foot sensor, advanced console.
- Estetica a terminale ASCII in verde (ispirata ai terminali di Fallout) / Green ASCII terminal look inspired by Fallout terminals.

## Pairing
1. Accetta la richiesta di accoppiamento Bluetooth di Android / Accept Android's Bluetooth pairing request.
2. Quando il log scrive ">>> PREMI ORA UN PULSANTE SULLA SCARPA <<<" premi un pulsante sulla scarpa / When the log says ">>> PRESS A BUTTON ON THE SHOE NOW <<<" press a button on the shoe.

Se la scarpa rifiuta il pairing / If the shoe refuses to pair: reset di sistema / system reset:
1. Tieni premuti entrambi i pulsanti 5 secondi, rilascia con i LED rossi / Hold both buttons 5 seconds, release when the LEDs are red.
2. Tieni premuto un pulsante; quando le luci si accendono premi l'altro 3 volte fino al verde / Hold one button; when the lights come on press the other 3 times until green.
3. Cancella la scarpa dal Bluetooth del telefono / Forget the shoe in the phone's Bluetooth settings.
